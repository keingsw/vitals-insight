# vitals-insight
Web Vitals を計測する RUM サービス

設計・実装・運用を通じて、フロントエンド、AWS、システム設計のスキルをブラッシュアップするための学習用プロジェクト

## やること
- 計測: SDK をサイトに埋め込み、LCP、INP、CLS と原因の情報(attribution)を集める
- 収集: ページを閉じるときも含めて、イベントを AWS に送って取り込む
- 集計と可視化: メトリクスを集計して、ダッシュボードで推移と遅い要素を見られるようにする
- 検知と説明: 悪化を検知して、原因の候補を説明する

## やらないこと
- 商用サービスとしての運用
- 既存の RUM 製品に並ぶような機能の充実
- Web Vitals 以外の計測 (エラー監視など)
